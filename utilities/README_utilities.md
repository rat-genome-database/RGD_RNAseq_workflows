# Utilities

Standalone scripts for re-running or correcting specific steps outside of the main RNAseq pipeline.

---

## Scripts

| Folder | Purpose |
|--------|---------|
| [`combined_project_processing/`](./combined_project_processing/README_combine_workflow.md) | Merges RNAseq workflow output directories that belong to the same BioProject but were processed in separate runs (for example, paired-end vs. single-end libraries, or different read lengths) into one output directory. |
